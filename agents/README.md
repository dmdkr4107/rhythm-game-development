# 에이전트 안내

개발·테스트 에이전트의 설정과 협업 절차를 찾기 위한 폴더입니다.

- [개발 에이전트](../.codex/agents/game_developer.toml): 요청된 기능 구현과 실패 원인 수정
- [테스트 에이전트](../.codex/agents/game_tester.toml): 독립 검증과 오류 보고
- [하네스 사용법](../docs/HARNESS.md): 개발 → 테스트 → 수정 → 재검증, 최초 검증 포함 최대 3회

실제 역할 정의는 기존 `.codex/agents/`에서 관리합니다. 이 폴더에 설정을 복제하지 않습니다.
