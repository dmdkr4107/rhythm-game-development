# 프로젝트 분석과 개선 제안

기준일: 2026-10-19. 게임 코드, HTML/CSS, Firebase 연동 코드, 테스트와 개발 문서를 검토했다. 이번 작업에서는 게임 규칙을 바꾸지 않았다. 이전 작업의 미커밋 변경을 유지했다. 아래 성능 항목은 측정 전 코드 관찰이며, 실제 병목으로 확정한 내용과 구분한다.

## 분야별 남은 확인

### 판정과 입력

- 일반 노트와 롱노트의 PERFECT/GOOD/MISS 경계를 표로 확정한다. 이른 입력·늦은 입력을 대칭으로 할지, 롱노트 시작과 끝을 각각 집계할지 결정이 필요하다.
- 프레임 사이에 생성될 노트에 대한 입력, 같은 레인의 근접 노트, 키보드와 터치 동시 사용을 검증한다. 현재 키보드와 터치는 `lanePress`를 공유한다.
- 키 설정에서 Escape·Enter·Space와 다른 예약 키를 배정할 수 있다. 메뉴 우선 처리와 충돌하므로 허용 키 정책과 안내가 필요하다.
- 창 포커스 상실과 탭 전환 시 입력 해제·자동 정지를 검토한다. 갑작스러운 자동 정지는 플레이 정책 변경이므로 먼저 동작을 정한다.
- 현재 회귀 검사에서 +81ms 처리 순서 차이를 확인한 것은 문제 재현이며, 올바른 규칙으로 검증을 마쳤다는 뜻이 아니다.

### 음악과 종료

- 디코딩 실패는 콘솔 오류만 남긴다. 시작 대기 상태에서 벗어날 수 있는 오류 안내·재시도·곡 선택 복귀 기능을 권장한다.
- `AudioContext.resume()`와 `suspend()`의 Promise 실패 및 연속 조작을 다루는 상태 관리가 필요하다. 실제 브라우저에서 오디오가 시작됐는지 확인해야 한다.
- 곡 미리듣기 소스는 본 게임의 `stopMusic`과 별도로 관리된다. 지연된 미리듣기 요청이 화면 이동 후 실행되거나 본 게임과 겹치는지 재현 검사가 필요하다.
- 종료는 등록된 곡 길이와 노트 상태를 사용한다. 디코딩된 실제 길이, 마지막 롱노트 끝, 싱크 오프셋을 비교하는 채보 검증을 추가한다. 오디오 종료만으로 결과 화면을 열면 남은 노트를 잃을 수 있으므로 종료 규칙을 먼저 정한다.
- 기존 싱크 테스트는 타이머와 탭 평균을 사용한다. 중앙값·이상치 제외·반복 측정과 설정 저장을 권장하며, 오프셋 부호와 실제 보정 방향을 검증해야 한다.

### 성능

- 정적 배경 캐시와 HUD 값 변경 시에만 갱신하는 처리는 이미 있다. 유지한다.
- 노트별 그라디언트·그림자 생성, 이펙트 순회와 배열 필터링을 프로파일링한다. 측정 없이 객체 풀이나 복잡한 자료구조를 도입하지 않는다.
- 이펙트 수명(`age += .05`)과 레인 플래시는 프레임당 상수로 갱신한다. 60Hz와 144Hz에서 표시 시간이 다를 수 있어 경과 시간 기반으로 전환을 검토한다. 노트 판정 시간과는 별개다.
- 저사양 기기를 위한 이펙트 강도 설정을 권장한다. 기본 화면을 유지하고 사용자가 선택하도록 한다.

### 구조와 사용자 기능

- 볼륨·키 배치·싱크 설정 저장, 초기화, 버전별 기본값 처리를 추가하면 반복 설정을 줄일 수 있다. 저장값 타입·범위 검사도 필요하다.
- 결과 화면에 EARLY/LATE 횟수와 오차 분포를 추가하면 연습과 싱크 진단에 도움이 된다. 실측 없는 자동 보정은 피한다.
- 연습 모드의 구간 반복·속도 변경은 유용하지만 재생 위치·채보 시간·점수 규칙이 함께 바뀌므로 별도 설계와 승인이 필요하다.
- Firebase SDK 일부만 로드된 후 재시도하는 경로, 로그인 사용자 변경 중 늦게 도착한 데이터 조회, 보상 지급과 초기 조회의 경쟁 상태를 별도 검사한다. 운영 전 서버 규칙과 보상 검증이 필요하며 이번에는 서버 데이터를 변경하지 않았다.

## 다음 작업의 완료 기준

1. 판정 정책 확정 후 세 모드에서 각 경계 -1/0/+1ms, 프레임 처리 순서 변경, 일반·롱노트 중복 판정 테스트 통과.
2. MP3·합성 곡 각각 초반·중간·후반과 반복 정지 후 오차 기록. 허용 오차는 기기와 목표를 정한 뒤 확정.
3. 30/60/144Hz를 모사한 시간 진행과 실제 브라우저 검사 구분. 실제 입력 지연은 기기·브라우저·출력 장치를 함께 기록.
4. 모든 곡·난이도 채보의 정렬, 레인 범위, 유효 숫자, 홀드 길이와 종료 시간을 검사.
5. 로딩 실패·저장소 차단·포커스 상실·재시작·터치 취소·로그인 실패 경로 확인.
