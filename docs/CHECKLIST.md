# 동작 확인 체크리스트

게임 코드는 있지만 이번 문서 이관 작업에서는 실제 실행·플레이 테스트를 하지 않았으므로 모든 항목을 미완료로 유지합니다. 코드에 기능이 있다는 사실만으로 완료 표시하지 않습니다. 현재 구성과 검증 질문은 `PLAN.md`를 참고합니다.

## 시작·재시작

- [ ] 시작 동작이 게임을 한 번만 시작하며 초기 상태를 올바르게 설정한다.
- [ ] 결과 화면의 RETRY(다시 하기) → 곡 선택 → START로 다시 시작할 때 음악 시간, 노트 상태, 입력 상태, 점수와 콤보가 초기화된다.
- [ ] 반복해서 재시작해도 음악이나 노트 처리가 중복 실행되지 않는다.

## 키 입력

- [ ] 결정한 조작 키 또는 입력 장치로 의도한 입력이 처리된다.
- [ ] 키 누름·뗌, 길게 누름에 따른 반복 입력, 동시 입력이 합의한 규칙대로 처리된다.
- [ ] 입력이 누락되거나 중복 처리되지 않으며 입력 지연을 측정·기록한다.

## 음악·노트 동기화

- [ ] 음악 기준 시간과 노트 시간이 일치하며 시작과 재시작 때 기준 시간이 맞는다.
- [ ] 곡의 초반·중간·후반에서 노트와 음악이 합의한 허용 오차 안에 맞는다.
- [ ] 화면 갱신 속도가 달라져도 시간 차이가 누적되지 않는지 확인한다.

## 판정 경계

- [ ] 각 판정의 시간 경계 직전·경계값·경계 직후 입력이 정한 규칙과 일치한다.
- [ ] 이른 입력과 늦은 입력, 미입력에 대한 판정이 정확하다.
- [ ] 하나의 노트가 중복 판정되지 않고 한 입력이 의도하지 않은 여러 노트를 처리하지 않는다.

## 점수 계산

- [ ] 각 판정별 점수와 콤보 변화가 정한 규칙의 예상값과 일치한다.
- [ ] 미입력과 실패 판정의 점수·콤보 처리가 정한 규칙과 일치한다.
- [ ] 여러 노트의 합계와 최종 결과 점수가 일치하고 재시작 시 초기화된다.

## 음악 종료

- [ ] 음악 종료 시 정한 종료 동작과 결과 화면이 실행된다.
- [ ] 종료 시 남은 노트를 정한 규칙대로 처리한다.
- [ ] 종료 후 입력이 점수를 바꾸지 않으며 재시작할 수 있다.
