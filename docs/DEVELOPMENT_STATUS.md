# 리듬게임 개발 문서

**프로젝트:** rhythm-game-development  
**개발 방식:** AI 활용 개발  
**기준일:** 2026년 10월 18일

## 1. 프로젝트 소개

HTML, CSS, JavaScript를 이용해 제작한 웹 기반 4레인 리듬게임이다. 음악에 맞춰 노트를 입력하고 점수와 콤보를 획득하는 방식으로 진행된다.

## 2. 구현된 주요 기능

- 4레인 노트 및 롱노트
- EASY / NORMAL / HARD 난이도
- PERFECT / GOOD / MISS 판정
- 점수, 콤보, 정확도 표시
- 곡 선택 및 결과 화면
- 키 설정 및 음악 싱크 조절
- 스킬 트리와 스킨 시스템
- Firebase 회원가입 및 로그인
- 최고 기록 및 일부 설정 저장

> 위 기능은 코드와 개발 문서에서 확인한 내용이며, 전체 실행 검증이 끝난 상태는 아니다.

## 3. 완료된 개발 작업

- 기존 게임 파일과 원본 분리 및 보존
- GitHub 저장소 구조 정리
- AI 개발 규칙 및 테스트 계획 작성
- JavaScript 자동 문법 검사 구축
- 필수 파일 및 HTML 참조 검사 구축
- Firebase 로그인 초기화 중복 실행 방지
- GitHub 자동 검사 통과

## 4. 오류 수정 기록

### Firebase 로그인 초기화 문제

- **문제:** 로그인 시스템을 연속해서 다시 불러오면 초기화 작업이 중복 실행될 가능성이 있었다.
- **수정:** 진행 중인 초기화 작업을 재사용하도록 변경했다.
- **추가 개선:** Firebase SDK 준비 상태 확인 및 초기화 성공 시 이전 실패 상태 초기화
- **검사 결과:** 자동 정적 검사 통과
- **미확인:** 실제 계정 로그인 및 재시도 동작

## 5. 남은 작업

- 게임 로직 상세 코드 리뷰
- 노트 판정과 MISS 처리 검증
- 음악과 노트의 싱크 확인
- 롱노트 입력 및 점수 계산 검증
- 일시정지와 재시작 오류 검사
- 실제 브라우저 플레이 테스트
- 필요에 따른 추가 기능 개발
- 최종 제출 자료 정리

## 6. 개발 시 주의 사항

- 기존 리듬게임 원본은 보존한다.
- 오류를 확인한 후 작은 단위로 수정한다.
- 수정 후 자동 검사와 실제 플레이 테스트를 구분한다.
- 사용자 요청 없이 GitHub에 추가 업로드하지 않는다.
- 검증되지 않은 기능은 완료로 표시하지 않는다.

## 7. 현재 결론

게임의 기본 기능과 GitHub 자동 검사 환경은 구축되어 있다. Firebase 초기화 관련 오류도 일부 수정했다. 다만 게임의 판정·음악 동기화·점수 계산 등에 대한 상세 검증이 남아 있으므로 추가적인 코드 리뷰와 플레이 테스트가 필요하다.
