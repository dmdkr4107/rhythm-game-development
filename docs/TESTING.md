# 리듬게임 검증 안내

자동 검사는 GitHub Actions의 `Validate rhythm game` 워크플로에서 실행됩니다.

## 자동 검사 범위

- `assets/js/game.js`, `assets/js/firebase.js` JavaScript 구문 오류 확인 (`node --check`)
- 메인 HTML, 스타일, 게임 스크립트, Firebase 스크립트, 원본 보관 파일 존재 여부 확인
- `index.html`의 CSS/JS 참조 및 주요 게임 UI 요소 확인

**주의:** 자동 검사 성공은 리듬게임이 정상 작동한다는 뜻이 아닙니다. 소리, 노트 판정, 점수 계산, 키 입력 지연, Firebase 인증은 검증하지 않습니다.

## 로컬 실행

Python이 설치된 컴퓨터에서 저장소 폴더를 연 후:

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 접속.

## 실제 플레이 확인 순서

1. 시작 화면에서 곡 선택, 난이도 변경, START 확인
2. A/S/K/L 키의 단일·동시 입력 및 롱노트 누르기·떼기 확인
3. PERFECT/GOOD/MISS 표시와 점수, 콤보, 정확도 변화 확인
4. ESC 일시정지 후 재개 시 음악과 노트 싱크 확인
5. 곡 종료 후 결과 화면 확인, RETRY로 다시 시작해 상태 초기화 확인
6. MP3 곡과 합성 곡을 각각 테스트하고 노트와 음악의 싱크 확인
7. 오류가 발생하면 날짜/브라우저/곡/난이도/재현 방법/예상 결과/실제 결과를 `docs/CHECKLIST.md`에 기록

Firebase 로그인 검증 시 테스트 계정을 사용하고 비밀번호를 이슈나 문서에 적지 마세요.

## 후속 코드 리뷰

게임 로직의 본문을 모두 읽고 실제 오류를 재현한 뒤 최소 범위로 고칩니다. 코드나 실행 결과를 확인하기 전에는 버그 수정 완료라고 기록하지 않습니다.
