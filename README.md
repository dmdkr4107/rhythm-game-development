# 리듬게임

브라우저에서 실행하는 네온 테마의 4레인 리듬게임입니다. 하재범 리듬게임 v3.3.6 최적화 버전을 바탕으로, 게임 화면·스타일·스크립트를 나누어 GitHub에서 관리하기 쉽게 정리했습니다.

## 주요 기능

- 4레인 노트와 롱노트, 타이밍 판정, 점수·콤보·정확도 표시
- 곡 선택과 EASY / NORMAL / HARD 난이도
- 키 설정, 노트 크기, 사운드 볼륨, 싱크 조절과 싱크 테스트
- 스킬 트리와 배경·노트·타격음 스킨
- 브라우저에 최고 기록과 일부 설정 저장
- Firebase를 사용하는 회원가입·로그인 및 사용자 데이터 연동 코드

## 폴더 구조

```text
리듬게임/
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   └── js/
│       ├── game.js
│       └── firebase.js
├── archive/
│   └── rhythm_game_v3_3_6_optimized.html
├── .gitignore
└── README.md
```

`index.html`은 메인 실행 화면, `styles.css`는 게임 스타일, `game.js`는 게임 로직과 내장 오디오, `firebase.js`는 Firebase 로딩과 인증·데이터 연동을 담당합니다. `archive/`에는 수정하지 않은 원본을 보관합니다.

## 실행 방법

1. 저장소를 내려받거나 클론합니다.
2. 저장소 폴더에서 다음 명령을 실행합니다. Python이 필요합니다.

```bash
python -m http.server 8000
```

3. 브라우저에서 <http://localhost:8000>을 엽니다.
4. 곡과 난이도를 선택하고 게임을 시작합니다.

## 조작 방법

| 키 | 동작 |
| --- | --- |
| A / S / K / L | 왼쪽부터 4개 레인의 노트 입력 |
| Enter / Space | 타이틀에서 곡 선택으로 이동, 곡 선택 화면에서 게임 시작 |
| 방향키 | 곡 선택 화면에서 이전·다음 곡 선택 |
| Esc | 플레이 중 일시정지, 곡 선택 화면에서 타이틀로 복귀 |

롱노트는 해당 키를 길게 누르고 끝나는 타이밍에 놓습니다. 레인 키는 게임의 키 설정 화면에서 변경할 수 있습니다.

## 현재 버전 안내

- 원본의 게임 동작을 유지하면서 스타일과 두 스크립트를 분리했습니다. 스크립트 로드 순서도 유지했습니다.
- 원본의 개발 모드(`DEV_MODE = true`)가 유지됩니다. 이 모드에서는 골드·다이아가 무제한이며 스킬 트리의 모든 노드를 구매할 수 있습니다.
- Google Fonts와 Firebase SDK를 불러오므로 해당 기능에는 인터넷 연결이 필요합니다.
- Firebase 로그인과 데이터 저장은 원본에 설정된 프로젝트에 연결됩니다. 새 배포 주소에서 인증을 사용하려면 해당 Firebase 프로젝트의 인증 허용 도메인과 데이터 접근 규칙을 확인해야 합니다.
- 별도의 이용 허가 라이선스는 지정하지 않았습니다. 포함된 음악 등 자산의 배포 권한은 각 권리자의 조건을 따릅니다.
